# Offline discovery guidance

Use this only when live App Hub MCP resources are unavailable.

- Capture the intended workload, interfaces, data sources, resource needs, target Torizon hardware, OS constraints, and production requirements.
- Explain that application availability, versions, publisher standing, popularity, and compatibility require a live catalog check.
- Suggest searching by small capability terms such as monitoring, MQTT, visualization, camera, fieldbus, or device management after connectivity returns.
- For evaluation, favor a small reversible proof of concept. For product work, require maintained source, documented configuration, support expectations, security review, and a hardware test plan.
